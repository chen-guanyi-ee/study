# Token System

Always-on context discipline for study work.

## Default Loop

1. Orient from `bootstrap.md`, `loadout.md`, and this file.
2. Load one routed method file only when the task needs it.
3. Retrieve exact evidence: section, figure, table, equation, snippet, or file.
4. Compress observations into the answer or artifact; do not carry raw dumps.
5. Verify with the cheapest useful check before finalizing.

## Rules

- Spend tokens on facts that change the answer.
- Use `rg`, indexes, headings, and source maps before opening long files.
- Prefer snippets over whole files and cropped figures over whole pages.
- Keep generated caches, logs, virtual environments, and agent state out of
  search/load paths unless explicitly needed.
- Reference existing files instead of repeating their rules.
- Write durable memory only for stable preferences, reusable methods, or
  conclusions that improve future study work.

## Long Tasks

Keep a compact working state when a task spans many steps:

```text
Question:
Method:
Sources:
Useful facts:
Uncertainty:
Next check:
```

Drop scratch text once the useful fact, pointer, or decision is captured.
