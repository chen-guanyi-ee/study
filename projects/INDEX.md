## Loading Rule

Read the one project file routed by `../loadout.md` or this index. Do not read
every project file unless the user explicitly asks for a workspace-wide audit or
the current cleanup task requires it. Do not pull in agent cache/state folders
or other generated noise unless the task specifically needs them.
