# Study Bootstrap

This folder is the local study-method workspace.

## Always Read

For normal study work, read only:

- `loadout.md`

That file is the compact route map. Do not eagerly load longer files unless
`loadout.md`, the user request, or the current task clearly requires them.

## Read When Relevant

- Use the routing section in `loadout.md` for project-specific files.
- Read `memory/current.md` only when durable study facts beyond the compact
  loadout matter.
- Read `policy.md` only when revising study workspace boundaries.
- Generated toolchains, virtual environments, caches, logs, and agent-state
  folders are not context sources by default.
- For broad work, prefer indexes, summaries, targeted search, and relevant snippets over reading whole repositories or long files.

## Update Rules

- Keep `loadout.md` short. It should stay suitable for every-turn loading.
- Put stable facts in `memory/current.md`; avoid raw transcripts and noisy activity logs.
- Study workspace rules live in `policy.md`; do not duplicate them here.

## Core Principle

Keep the study workspace domain-specific. Do not index unrelated implementation,
maintenance, or personal-continuity material here.
